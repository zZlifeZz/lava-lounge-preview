# Lava Lounge — website concept

A static, seven-page presentation project for a proposed lounge experience.

The pages demonstrate a mobile-friendly menu, local favourites, interactive seating concepts, an editorial shisha page with illustrative aroma profiles, event concepts, a local-only enquiry preview and browser-local owner controls. Menu items, prices, interiors and programme details are illustrative. No real orders, bookings or payments are processed. No visitor data is transmitted by the demo forms. The separately labelled receptionist demo uses the dedicated sales number, not an official venue number.

Built with plain HTML, CSS and JavaScript. The project is configured for the `/lava-lounge-preview` GitHub Pages path, with `.nojekyll` at its root. The Table 07 QR opens `/lava-lounge-preview/menu/?table=07`.

This repository contains only the public presentation website. Production business hosting and any live booking or menu-management system are outside this demo.

The October 2026 refresh preserves every existing public route and QR destination. Fonts and images are served locally; no third-party analytics or paid services were added. See ASSET_CREDITS.md for photography and typeface sources.
