# Lava Lounge — website concept

A static, six-page presentation project for a proposed lounge experience.

The pages demonstrate a mobile-friendly menu, local favourites, seating concepts, event concepts, a local-only enquiry preview and browser-local owner controls. Menu items, prices, images and programme details are illustrative. No real orders, bookings or payments are processed. No visitor data is transmitted by the demo forms.

Built with plain HTML, CSS and JavaScript. The project is configured for the `/lava-lounge-preview` GitHub Pages path, with `.nojekyll` at its root. The Table 07 QR opens `/lava-lounge-preview/menu/?table=07`.

This repository contains only the public presentation website. Production business hosting and any live booking or menu-management system are outside this demo.
